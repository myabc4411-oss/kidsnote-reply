개인정보 처리방침

1. 수집하는 정보

알림장 답장 도우미(이하 "앱")는 사용자의 개인정보를 수집하거나 별도 서버에 저장하지 않아요. 회원가입과 로그인도 없어요.

2. 기기에 저장되는 정보

아래 정보는 사용자의 기기(브라우저 저장소)에만 저장되고, 개발자나 제3자에게 전송되지 않아요.

  • 아이 이름, 선생님 호칭 (사용자가 직접 입력한 경우)
  • 말투·길이 선택, 작성 중이던 알림장 글(초안)
  • Gemini API 키 (사용자가 직접 입력한 경우)

설정 화면의 "저장된 데이터 모두 지우기"로 언제든 삭제할 수 있어요. 앱을 삭제하거나 브라우저 데이터를 지워도 삭제돼요.

3. AI 기능 사용 시 외부 전송

사용자가 직접 Gemini API 키를 입력한 경우에만, 사용자가 붙여넣은 알림장 글과 아이 이름·선생님 호칭이 답장 문구 생성을 위해 Google의 Gemini API로 전송돼요. 이 데이터는 Google의 개인정보 처리방침과 약관에 따라 처리돼요. 키를 입력하지 않으면 어떤 글도 외부로 전송되지 않고, 기기 안에서 기본 문구로 만들어요.

알림장 글에 다른 사람의 이름이나 민감한 정보가 있다면 AI 기능을 쓰기 전에 확인해 주세요.

4. 클립보드

사용자가 "복사한 글 붙여넣기" 버튼을 직접 누를 때만 클립보드의 글을 읽어 입력칸에 채워요. 앱을 열거나 화면을 전환할 때 자동으로 읽지 않아요. 이 내용은 위 2~3번에서 설명한 범위 밖으로 사용되지 않아요.

5. 광고와 분석

광고, 사용자 추적, 분석 도구를 사용하지 않아요.

6. 비공식 앱 안내

키즈노트는 해당 사업자의 상표예요. 이 앱은 키즈노트와 제휴하거나 승인받은 서비스가 아니고, 키즈노트의 계정이나 데이터에 접근하지 않아요.

7. 문의

개인정보와 관련한 문의는 앱 배포 페이지(GitHub 저장소)의 Issues로 남겨 주세요.
